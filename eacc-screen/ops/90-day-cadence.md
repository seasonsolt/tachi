# 90-Day Content Cadence — e-acc.ai

## Weekly operating constraints
- Time budget: **5–10 hours/week**.
- Default publishing cadence: **1 workflow every 1–2 weeks**, **1 comparison every 3–4 weeks**.
- Workflow pages remain the priority asset; comparison pages ship only when they strengthen an existing workflow cluster.
- `e-accs.com` remains deferred for the full 90-day window.

## 12-week schedule
| Week | Hours | Output target | Revenue / measurement task | Notes |
| --- | --- | --- | --- | --- |
| 1 | 8 | Finalize templates + home + 2 hubs | Stand up ledger + baseline analytics naming | Architecture + docs week |
| 2 | 8 | Publish 3 launch workflows + 1 comparison + ritual route linkback | Validate pageview + CTA + newsletter events | Minimum meaningful launch |

| 9 | 5 | Publish comparison #3 | Re-check revenue-source mix | No new domain work |
| 10 | 6 | Publish workflow #7 | Update top-cluster ranking | Expand only winning clusters |
| 11 | 5 | Publish workflow #8 | Prep month-3 revenue summary | Reach 8 workflow target |
| 12 | 6 | Publish comparison #4 + 90-day review | Decide go / hold for next cluster or second domain | Validation checkpoint |

## 90-day targets
- **8 workflow/tutorial pages** published.
- **4 comparison pages** published.
- **1 homepage**, **2+ hubs**, and **1 preserved ritual route** live.
- **>= $50/month** revenue run rate measured via the weekly ledger.

## Operating rules
1. A comparison page is not eligible unless it supports an already-published workflow or imminent workflow.
2. Every weekly review updates the revenue ledger before new expansion work begins.
3. If hours drop below 5 in a given week, prioritize refresh + measurement over net-new publishing.
4. If a cluster underperforms for 4 straight weeks, prune it instead of starting a new domain.

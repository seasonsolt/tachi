# Cluster angle
This hub is for solo operators running multiple AI tools, prompts, and sessions without a full ops team. The goal is a weekly maintenance rhythm that keeps the stack trustworthy.

## Start here
1. Run a weekly audit for prompts, spend, and stale experiments.
2. Feed audit insights back into the live revenue ledger.
3. Expand into automation only after the audit loop is stable.

## Monetization posture
The hub should bias toward newsletter capture and lightweight ads. Product or affiliate CTAs only belong on downstream workflow pages where the tooling is part of the operating system.

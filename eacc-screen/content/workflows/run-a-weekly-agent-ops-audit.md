# Problem
Agent usage sprawls quickly: prompts drift, experiments pile up, and spend hides inside too many tools.

## Outcome
A 30-minute weekly audit that keeps prompts, active workflows, and revenue tracking aligned.

## Tool stack
- Prompt inventory
- Session or experiment log
- Weekly revenue ledger
- One simple action list for the next seven days

## Prerequisites
- Named workflows or experiments
- A home for weekly metrics
- Agreement that stale experiments get archived

## Build steps
1. Review active workflows and mark anything stale.
2. Check which pages or tools earned clicks or revenue.
3. Archive dead prompts and keep only reusable patterns.
4. Publish one action list for the next week.

## Failure modes
- Trying to audit everything daily
- No single place for revenue-source truth
- Letting the ritual lab become the only visible product surface again

## Alternatives
If the stack is still tiny, do a shorter Friday review and only graduate to the full audit once revenue tracking begins.

## Inputs for the ledger

A useful weekly ledger combines four signals:

- pageviews on each crawlable route,
- outbound CTA clicks by route,
- newsletter captures by route,
- revenue by source category.

## Weekly review prompts

1. Which cluster produced the highest-intent action?
2. Which page earned attention but no CTA clicks?
3. Which route deserves an update instead of a brand-new article?
4. Is the ritual screen still supporting brand memory without stealing the homepage?

## Output

The ledger should produce one decision per week:

- double down on a cluster,
- refresh a page,
- publish a support comparison,
- or prune something that only looks interesting.

## Why this matters for phase 1

The north star is not vanity traffic. The target is a transparent path to **$50/month** on the main domain, using a system the operator can keep alive without paid acquisition.

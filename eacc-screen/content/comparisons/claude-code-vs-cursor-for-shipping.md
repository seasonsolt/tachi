## Quick positioning

Use **Claude Code** when you want repo-aware execution with a strong task loop. Use **Cursor** when the editing surface itself is the product you want to live in all day.

## When Claude Code wins

- You want implementation and verification tied together.
- You care about task ownership, route-level acceptance, and shell-backed evidence.
- You want to preserve a clear line between plan, code change, and proof.

## When Cursor wins

- You want an integrated editor-first experience.
- You are exploring rapidly and want a broad suggestion surface.
- You are optimizing for time inside the IDE rather than explicit worker protocols.
